# mmr-ml

ME 405 project data: short-window frequency/phase/amplitude estimation for magneto-mechanical resonators.

- `raw/` - original files, untouched, git-ignored (see raw/README.md)
- `processed/` - outputs of the notebook
- `scripts/mmr_data.py` - loading, cleaning, reference fit, table builder
- `notebooks/hw1_item4_data_collection.ipynb` - HW1 item 4
- `metadata.yaml` - source, license, layout, processing parameters, column dictionary

Requirements: numpy, scipy, pandas, h5py, matplotlib, pyyaml
